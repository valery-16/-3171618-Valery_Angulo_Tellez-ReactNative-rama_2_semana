# Natura Glamping — Proyecto Semana 02

Bootcamp React Native — Semana 02 (FlatList y Búsqueda)

## Objetivo

Construir una aplicación móvil que permita visualizar y buscar alojamientos tipo glamping utilizando `FlatList`, `TextInput` y componentes reutilizables en React Native.

---

## Dominio

Glamping (campamento de lujo)

La aplicación muestra diferentes opciones de glamping en Colombia, incluyendo:

- Nombre del lugar
- Ubicación
- Precio por noche
- Capacidad de personas
- Categoría del glamping

---

## Funcionalidades

- Lista dinámica de glampings usando `FlatList`
- Búsqueda en tiempo real con `TextInput`
- Filtrado por nombre, ubicación y categoría
- Estado vacío cuando no existen resultados
- Tarjetas reutilizables mediante `ItemCard`
- Interacción con tarjetas usando `Pressable`
- Al hacer clic se muestra una alerta con el nombre del glamping
- Separación visual entre tarjetas
- Diseño responsive y moderno

---

## Tecnologías utilizadas

- React Native
- Expo
- TypeScript
- FlatList
- Hooks (`useState`, `useMemo`, `useCallback`)
- Flexbox

---

## Cómo ejecutar el proyecto

```bash
pnpm install
pnpm start
```

### Opciones de ejecución

- Presionar `a` para abrir en Android
- Presionar `w` para abrir en navegador
- Escanear el código QR con Expo Go

---

## Requisitos cumplidos

- FlatList con `keyExtractor`
- Búsqueda funcional en tiempo real
- Uso de `useMemo` para optimización
- Uso de `useCallback`
- Estado vacío personalizado
- Componente reutilizable `ItemCard`
- Uso de `KeyboardAvoidingView`
- Theming con constantes globales
- Tipado estricto con TypeScript
- Diseño usando Flexbox

---

## Diseño visual

La aplicación utiliza una interfaz oscura inspirada en naturaleza y turismo ecológico:

- Fondo oscuro
- Tarjetas modernas
- Texto blanco para mejor contraste
- Emojis decorativos relacionados con glamping
- Diseño minimalista y limpio
